- **블로그 워터마크("태영목공") 박힌 컷** — 사진 중앙부에 있어 크롭으로 못 지운다:
  `223915353762_05`, `224042518096_12/20/21/22/23`.
- **폰 화면 캡처(상단 상태바·하단 내비바 포함)** — 원본 그대로 쓰면 상태바가 보인다:
  `223915353762_15/17`. `223915353762_17`(=`case-suji-door.jpg`)은 상하 크롭(3.6% / 6.7%)해서 썼다.
- `221464765597_19` 는 사진이 아니라 **전화번호가 박힌 홍보 이미지**다.

## 처리 규격

- `sharp` 로 `.rotate()`(EXIF) → 가로 최대 1200px → `jpeg quality 80, mozjpeg`.
- 카드에서 실제로 보이는 4:3 / 16:10 / 1:1 크롭을 미리 합성해 눈으로 확인한 뒤 채택한다
  (중앙 크롭이라 세로로 긴 원본은 위아래가 크게 잘린다).
- 원본 450장은 `docs/research/blog-scrape/`(108MB) 에 있고 **커밋하지 않는다**(.gitignore).
  다시 받으려면 `blog.naver.com/woodty` 글 목록을 훑어 이미지를 저장하면 된다.
